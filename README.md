# Personal Portfolio Website

This is a modern, responsive personal portfolio website designed to showcase my software development projects, skills, and professional journey. The site features a clean user interface with dark mode support, smooth animations, and a project gallery with category filtering.

### 🚀 Technologies Used

**Frontend & Frameworks:**
*   **React 19:** For building a dynamic and component-based user interface.
*   **Vite 8:** As the next-generation frontend tool for fast builds and development.
*   **TypeScript:** For static type checking and improved developer experience.
*   **Tailwind CSS 4:** For utility-first styling and responsive design.

**Animation & Icons:**
*   **Framer Motion 12:** For implementing smooth transitions and interactive animations.
*   **Remix Icon:** A comprehensive library of neutral-style system symbols.
*   **Tech Stack Icons:** For displaying technology-specific icons in the skills and project sections.

**State & Utils:**
*   **React Hooks:** Utilized `useState`, `useEffect`, and `useRef` for managing component state and side effects.
*   **Lucide React / Remix Icon:** Used for consistent and modern iconography.

### ✨ Key Features
*   **Responsive Design:** Optimized for mobile, tablet, and desktop views.
*   **Project Filtering:** Browse projects by category (e.g., All, Web, Game Dev).
*   **Dark Mode Support:** Seamlessly toggle between light and dark themes.
*   **Loading Animations:** Custom entrance animations for a polished user experience.
